# Motor Place (Loja Automotiva Online)

## 1. Contexto
Este projeto consiste no desenvolvimento do front-end de uma loja automotiva online. A aplicação simula uma experiência de e-commerce, permitindo que usuários naveguem por veículos, visualizem detalhes e interajam com a interface de compra.

## 2. Público-alvo
O público-alvo são adultos entre 18 e 55 anos que desejam comprar veículos de forma prática e segura pela internet. A plataforma é acessada via web, com foco principal em dispositivos móveis, garantindo também uma navegação eficiente em desktops e tablets.

## 3. Dor principal
Atualmente, usuários têm dificuldade em encontrar rapidamente veículos que atendam às suas necessidades em plataformas com navegação pouco intuitiva, filtros limitados ou informações incompletas.

## 4. Critério de sucesso
O usuário consegue encontrar e visualizar um produto desejado em poucos cliques e sem dificuldades de navegação.
